# Data and saved checks

[Browse selected data summaries in Git](ORIGINALS.md). The reviewed evidence Release contains 108,908 unique screened data objects, plus reports, code, logs and provenance. Large checkpoint and per-case collections live in that Release rather than ordinary Git.

The [legacy facts table](legacy-round14/facts.json) is a separate minimal historical deposit. Its [original scope note](../reports/legacy-round14/counters-scope.original.md) explains omitted inputs and scoring assets. Recorded scores, counters, control successes and checksum matches are distinct claims; archiving did not recompute the research.

Source images, raw books/pages, dictionaries/models, pattern assets and binary formats still needing review are excluded or held externally. Original manifests can reference such external files; see [limitations](../LIMITATIONS.md).
