# Methodology

## Archive procedure

The assembly checked the authenticated organization's eleven repositories before creating Dorabella; no suitable dedicated archive existed. It created the repository private, then checked its empty remote refs/history before the user's separate public authorization was applied. Only this repository's visibility changed.

A complete metadata package accounted for 233 source objects. Its supplied SHA-256 was checked. Exact identified versions of 232 originals were downloaded, byte counts checked and SHA-256 values computed; the standalone third-party image was excluded. Original archive bytes remain intact outside Git. Archive members were inspected and hashed without executing bundled programs.

Static screening combined supplied per-member dispositions, archive membership, file-format checks, content markers, explicit British Library/source exclusions, and an additional dictionary/book/n-gram review. Identical hashes were deduplicated while all retained source-member/version mappings were preserved. Holds propagate to identical bytes rather than trusting a harmless alternate filename. Private locators, operational wrappers, raw source pages/images/books, model/dictionary/pattern assets, dependencies and unclear binary formats were held or excluded. Static triage is not a blanket license determination.

Only screened own-research bytes enter the public deposit. Git contains browseable small originals and English navigation; the Release ZIP contains the larger reviewed object set and provenance/hash manifests. The full private source inventory and download locators remain outside publication. Original-language files are not silently edited or redacted. New English explanations have separate identity and hashes.

## Evidence classes

Keep bounded negative results, method limitations, experimental candidates, historical control checks and primary sources distinct. Keep source transcription, literal model output and editorial interpretation separate. Reused regression controls are not new independent validation. A round trip or matching implementation can test algebra or code while leaving historical truth unresolved. Preserve protocol changes and adaptive choices rather than rewriting their history.

## Verification boundary

Permitted operations were file reads, copies, archive listings, metadata parsing, SHA-256 checks, link/path checks and Git/history inspection. All 196 embedded checksum assertions in the supplied inventory were independently matched against freshly downloaded members, including nested ZIPs. Neither this nor a hash establishes scientific correctness or rights.

No scorer, key search, calibration, experiment, historical rerun or cryptanalytic verifier was executed for this task. Stored instructions and shell commands remain inert text. A future reproducibility study requires its own explicit scope.
