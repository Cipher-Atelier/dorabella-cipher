# TS-ADAPTER-CONTRACT-v1 — prospective, до единственной попытки

Цель: законченная проверка собственного read-only API candidates(pattern,order),
is_word(word), maxlen и ограниченного LRU на уже верифицированном Storage-v2.
Это новый потребитель готового индекса, без его rebuild. Не solver, не scoring,
не доказательство Perl numerical equivalence. Только -n и проверенные ASCII-байты.

Индекс SHA256 c35f28462555da9982ed975b713a291b654a0e2b0d514e7d498f717bdf386070;
source SHA256 2849bc03f85c59a422f1945960ce04a4b6e66cc02c61a6484de0283c30c724fd.
Идентичности путей/размеров/кода/Python фиксируются в FREEZE.json. Старые артефакты read-only.

Фиксированы семь pattern: a, aa, ab, aba, abc, abcdefgh, !. Они заданы по форме,
включая известную максимальную группу abcdefgh, без ciphertext/языковой оптимизации.
Каждый полученный полный список сравнивается с независимым последовательным reader.
Он один раз проходит все 7548932 строки/340083717 байт, хранит только эти семь
списков и полный исходный order-1 словарь123619. Проверяет суммарные10662322
элемента и maxlen46; это не повтор полного build/readback Storage-v2.
API-проверки: 7 cold +8 fixed-cache +1 caller-mutation +7 reopen =23 полных сравнений.
Дополнительный fetch для изменения копии и2 запроса order2/3; всего26 реальных list calls.
16 фиксированных word probes;6 синтетических строк для сравнения membership trace
и результатов двух способов доступа к словарю. Ни одного Dorabella/control plaintext.

Позитивные fixtures имеют вручную заданные5 списков,9 слов,maxlen6 и10 результатов
сегментации. Независимые негативы:6 недопустимых API-входов,6 повреждений маленькой
БД,2 перестановки/подмены raw bytes. Отдельно query-only, отсутствие pattern/order,
модификация возвращённой копии. Они не меняют реальный индекс. Сегментационный
reference — собственная буквальная передача control flow NoSpace9–36, не независимое
доказательство этого алгоритма; сравнение с оригинальным Perl пока отсутствует.

LRU: максимум2 pattern и8MiB учтённого Python payload; при превышении список
полностью возвращается без кэширования, никогда не усекается. Word LRU1024.
SQL cache4MiB,mmap0,mode=ro,query_only. Списки копируются перед возвратом.
Не кэшируются similarity/score/top50 или сегментация. Кэш меняет только IO, не ответы.

Одна синхронная stdlib-попытка, pinned Python3.12.14 -I -S. 180с кооперативно от
нового инженерного T0 включая hashes/fixtures/stream/lookup/seal; не старый scientific T0.
AS256MiB,CPU170/180с,один файл≤32MiB,core0,nofile64. Никаких subprocess/threads/network.
При существующем attempt — отказ; никаких retry/resume/автоисправлений.
Входной ресурсный gate: memory.max=8GiB,current≤7GiB; stop при наблюдении current≥7.5GiB.
Это оставляет начальный запас≥1GiB для процесса с AS≤256MiB, но не резервирует соседнюю
нагрузку. Poll0.5с; не realtime hardkill/cgroup isolation/crash durability.
Размер выбранных списков≤7×63911, отдельного≤63911; wordcalls≤100000 на экземпляр.
Строка≤118052, source≤340083717, rows≤7548932, все лимиты неизменны после результата.
Экспозиция памяти ограничена выбранными списками/словарём; полный source не загружается.
Основание времени: предыдущий full build+readback118.65с; здесь без build и полной SQL
проверки, один последовательный scan плюс малое число lookup. Это обоснование попытки,
не гарантированное время; превышение означает STOP.

Во время scan готовится ограниченный≤16MiB исходный subset для БУДУЩЕГО оригинального
oracle: все исходные order1, все строки выбранных pattern, первая строка с maxlen46.
Сохраняются исходные номера строк и SHA; это технический fixture, не новое обучение.
Исходный порядок сохраняется. Такой subset содержит все кандидаты выбранных групп,
полный segmentation lexicon и исходный maxlen, не всю модель для поиска.

Успех: все явные сравнения/негативы, coverage cache hit/eviction, отсутствие изменений
индекса/source, normal exit0, elapsed≤180, raw receipt и отдельный hash/readback.
Статус PASS_ADAPTER_CONTRACT_ONLY. Любая ошибка/лимит STOP; пропавший receipt UNKNOWN.
Никаких исходных Perl imports, LM/scoring, поиска или дальнейшего автоматического запуска.
