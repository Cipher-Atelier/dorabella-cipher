Этот каталог дополняет восстановленный `dorabella_lab_round7.zip`. Все 7200 исходных файлов архива раунда 7 сохранены побайтово. Новый каталог не подменяет старые результаты.

## Что здесь действительно выполнено

1. Проверка 1250 старых кандидатных записей и полный детерминированный повтор двух старых процедур `noisy` для Hauer/Hartmeier.
2. Визуальная проверка знаков 3 и 11 на доступном факсимиле и сверка с Figure 2 Hauer; проверка страницы мемуаров с мартовским заголовком.
3. Полное перечисление 84 288 и 42 144 разных строк с теми же триграммами и двумя начальными/конечными знаками. Отдельно — обе искусственные смеси известных разночтений: всего 252 864 перечисленные строки на четырёх входах (не независимые документы).
4. Точная оценка геометрии строк и рисунка повторов `FORLIMALVERN` на этих конечных множествах. Никакой языковой оптимизации Dorabella в этой ветке нет.
5. Дополнительные условные проверки геометрии, явно выбранные после основного результата.
6. Два новых для сохранённой лаборатории отрывка настоящих писем Элгара: по 87 букв, известная случайная простая подстановка, по 39 триграммных контролей. Все 80 записей полностью посчитаны старым поиском ключа.

## Воспроизведение

Нужны Python и пакеты из `requirements_round8.txt`, а также компилятор C++17 (`g++`). Старые модели уже лежат в `../data`. Запускайте из корня распакованной лаборатории:

```bash
python -m pip install -r round8/requirements_round8.txt
python round8/audit_previous.py --repeat
python round8/exact_study.py
python round8/geometry_sensitivity.py
python round8/elgar_sensitivity.py --workers 4
python round8/final_checks.py
```

`exact_study.py` сам компилирует перечислитель, проверяет его на небольших полностью перебранных примерах и заново перечисляет оба основных множества. `geometry_sensitivity.py` предполагает, что основной этап уже выполнен. Сравнения квадратов расстояния производятся целыми числами в Z[√2], а не по округлённым порогам.

`elgar_sensitivity.py` использует готовые записи при наличии. Для полного повторения новых 80 поисков сначала сохраните резервную копию, затем удалите только `round8/results/elgar/records`. Не меняйте `inputs.json` и протокол; прежние этапы не удаляйте. Повторный запуск после ограничения времени корректно продолжает с готовых записей.

Основные результаты: `results/exact_summary.json`, `results/sensitivity_summary.json`, `results/elgar/summary.json`, `results/final_checks.json`. Все перечисленные последовательности сохранены в `results/*_trigrams.npz`. Поле `sequences` — массив uint8 формы N×87; знак = 3×orientation + arcs_zero_based.

## Разделение происхождения

- `imported/handoff_unverified.txt` — точная копия переданной записки. Она содержит результаты, код которых не был приложен к старому архиву.
- `imported/handoff_claim_status.json` явно отделяет заново проверенные утверждения от неподтверждённых в этом раунде. В частности, прежний результат языкового теста 105/999 НЕ пересчитывался.
- `sources/visual_observations.json` — просмотренные источники и наблюдения. Браузер показал изображения, но скачивание исходных байтов в контейнер не удалось; архив НЕ содержит обещанного raw-факсимиле и не выдаёт увеличение изображения за новые детали оригинала.
- `sources/elgar_excerpts.json` — два коротких вручную сверенных отрывка. OCR не использовался. Это текст письма в печатных мемуарах, а не найденная оригинальная рукопись письма.
- `frozen_exact_protocol.json` зафиксирован до полного перечисления. `frozen_sensitivity_protocol.json` — ПОСЛЕ первичных результатов; это честно указанная дополнительная диагностика. `frozen_elgar_protocol.json` зафиксирован до новых поисков.

## Главные ограничения

Физические признаки и первые две строки были выбраны в прежних исследованиях. Точные условные доли не учитывают всю историю выбора гипотез. Две опубликованные транскрипции не независимы; две смешанные версии — лишь проверки чувствительности. Два контрольных письма не представляют всю переписку Элгара. Словарь TextBlob имеет неполную библиографию: отсутствие автора во всех его источниках не гарантировано.

При фиксации триграмм и числа дуг/полярностей по строкам остаётся всего 29 допустимых строк, причём 26 имеют те же полные частоты знаков по строкам, что оригинал. Поэтому исчезновение отличия в этом узком множестве — не сильное опровержение геометрической особенности: контроль почти вырожден.
