# Dorabella — лаборатория раунда 10

**Подтверждённой расшифровки нет.** Это продолжение раунда 9, не новая самостоятельная лаборатория.

## Содержимое

- `prepare.py`, `data/elgar_letters.json`: 12 новых для проекта отрывков из опубликованной переписки; источники, страницы, правила отбора и нормализации.
- `table_search.py`: полный перебор 241 920 ключей с фиксированными алфавитными тройками.
- `frozen_protocol.json`: исходники, параметры, входы и модель закреплены до поиска.
- `data/inputs.json`: все 94 входа, в том числе 78 полных паросохраняющих контрольных последовательностей.
- `results/records/*.json`: все 94 исхода, ключи, лучшие восемь кандидатов, результаты переноса и SHA-256 полных численных массивов.
- `results/records/{hauer_real,hart_real}_scores.npz`: полные массивы всех ключей для двух транскрипций.
- `results/summary.json`, `results/audit.json`: сводка и проверки реализации.
- `regression_diagnostic.py`, `results/regression_diagnostic.json`: отдельная последующая проверка старой ошибки b/d.
- `data/old_round9_hashes.json`: хеши всех 7380 файлов предыдущего архива.

**Компактность поставки:** при исследовании все 94 матрицы оценок были рассчитаны, сохранены и проверены. Они занимают около 636 MiB. В передаваемый архив включены две матрицы реальных транскрипций, а не все 94. Для остальных сохранены входы, исходы, ключи и хеши содержимого матриц; `reproduce.py` восстанавливает их по тому же протоколу. Полный массив не нужен для получения сохранённого ответа. Отсутствующий массив не означает незавершённый контроль.

Исходные PDF и изображения не включены: их удалось просмотреть через веб-инструмент, но скачать байты в контейнер не удалось (DNS). Имеются ссылки, координаты и транскрипции коротких фрагментов, проверенные по изображениям печатных страниц, а не по автографам.

## Воспроизведение

Рабочая директория — `dorabella_lab`, зависимости как в предыдущих раундах, фактическая новая среда — `round10/environment.json`. Для исключения записи кэша в старые каталоги:

```bash
export PYTHONDONTWRITEBYTECODE=1
export NUMBA_CACHE_DIR="$PWD/round10/cache"
export OPENBLAS_NUM_THREADS=1

# Заново полностью пересчитать один вход, даже при наличии сохранённого результата:
python round10/reproduce.py --case hauer_real

# Пересчитать все 94 входа и проверить хеш каждого полного массива:
python round10/reproduce.py --all

# То же, сохранив недостающие матрицы (около 636 MiB для всех):
python round10/reproduce.py --all --save

# Проверки ключей, итогов, источников контролей и целостности старых файлов.
# audit.py также всегда повторяет шесть полных поисков:
python round10/audit.py
python round10/regression_diagnostic.py
```

`audit.py` сообщает фактическое число присутствующих матриц. При первоначальном аудите их было 94; в компактной поставке до восстановления будет 2. Исторический результат первоначального аудита записан в `results/audit_initial.json`, последующий запуск его не перезаписывает.

Для продолжения незавершённой серии: `python round10/table_search.py --workers 2 --max-new 10`. Он пропускает готовые JSON. Для полного пересчёта при готовых JSON предназначен `reproduce.py`; не удаляйте старые раунды.

## Область утверждений

241 920 — число уникальных полных ключей в узком классе `8! × 3!`, а не число всех моноалфавитных подстановок. Порядок букв внутри троек меняется **одной общей** перестановкой для всех направлений. Число дуг не исправляется; состояние, перестановка позиций и угаданные слова не вводятся.

Максимум составного языкового балла вычислен точно в этом классе. Сам балл остаётся эвристическим. Он не доказывает смысл или историческое использование класса. 12 новых текстов — удобная, связанная перепиской выборка; две старые регрессии считаются отдельно. Отложенный суффикс не участвует в подборе ключа по префиксу.
