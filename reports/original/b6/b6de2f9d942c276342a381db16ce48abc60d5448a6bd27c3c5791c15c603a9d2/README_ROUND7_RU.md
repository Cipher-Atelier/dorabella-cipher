# Dorabella — раунд 7

**Подтверждённой расшифровки нет.** Ни одна буква или правка исходного документа не считается установленной. Этот пакет дополняет раунды 1–6, не перезаписывая их код или результаты.

## Два новых вопроса

1. Сохраняется ли преимущество исходной последовательности в поиске простой подстановки над контролями, которые сохраняют **все частоты направленных соседних пар**, а не только частоты отдельных знаков?
2. Поможет ли совместный поиск буквенного ключа и небольших ошибок направления? Модель разрешает до четырёх замен направления на соседнее (±45°), но не меняет число дуг, порядок, длину или отдельные буквы независимо от ключа.

Эти процедуры **не являются калибровкой усиленного поиска 1 665 маршрутов** из шестого раунда. Тот пробел остаётся. Не выполнялось независимое слепое чтение изображения рукописи. Исправления, предлагаемые оптимизатором, не приняты в исходные транскрипции.

## Состав

- `conditional_v7.py`: собственная реализация эйлерова перемешивания с точными частотами пар, проверка генератора, равнобюджетный подбор простой подстановки на реальных/контрольных входах.
- `refine_conditional_v7.py`: дополнительное углубление поиска на обеих транскрипциях и всех 198 паросохраняющих контролях. Выбрано после просмотра начальных результатов; не выдаётся за предварительную регистрацию.
- `run_hart_refinement_v7.py`: только разделение вычислительной очереди между процессами, не другой алгоритм. Для воспроизведения не требуется.
- `noisy_v7.py`: совместный эвристический поиск таблицы букв и до четырёх локальных ошибок направления.
- `inputs_v7.py`: происхождение 12 новых отрывков Диккенса, фиксированные шифрования и ошибки, 19 согласованных пар отрицательных контролей. Входы уже включены; генератор не перезаписывает существующий файл.
- `count_bigrams_v7.py`: точное число последовательностей с заданными частотами пар и концами, с проверкой на полностью перечисленных коротких примерах.
- `summarize_noisy_v7.py`, `checks_v7.py`, `make_report_v7.py`: сводки, независимый пересчёт, технические проверки и журнал.
- `results/v7`: входы, фиксированные параметры/хеши, все законченные результаты, диагностика и журналы исполнения.

Старая символьная модель и словарь не переобучались. Зависимости закреплены в `requirements_round7.txt`, фактическая среда — `environment_round7.json`. SymPy требуется только для отдельного точного подсчёта числа паросохраняющих последовательностей.

## Воспроизведение

```bash
python -m venv .venv
# Активируйте окружение способом, принятым в вашей ОС.
pip install -r requirements_round7.txt
python conditional_v7.py --check-shuffle
python conditional_v7.py --workers 4
python refine_conditional_v7.py --workers 4
python noisy_v7.py --mode main --workers 4
python summarize_noisy_v7.py
python count_bigrams_v7.py
python checks_v7.py --repeat
python make_report_v7.py
```

Программы пропускают готовые записи. Для **чистого пересчёта** сначала сохраните копию архива, а затем удалите только подпапки `records` и `frozen.json` внутри `results/v7/conditional`, `results/v7/conditional_refined`, `results/v7/noisy`. Входные `inputs.json` оставьте: это обеспечивает те же тексты и случайные контроли. Затем выполните команды выше. Не смешивайте старые результаты с изменёнными параметрами.

В манифесте записан также абсолютный путь установленного словаря. Поэтому на другом компьютере при чистом пересчёте нужно заново создать манифест, как указано выше, а не выдавать несовпадающий путь за изменение словаря. Его содержимое проверяется SHA-256. Небольшие расхождения арифметики между версиями платформы возможны; сохранённый оригинальный пакет остаётся эталоном данного прогона.

Для повторения шести разработческих испытаний используется `python noisy_v7.py --mode dev --workers 4` после резервирования/удаления только `results/v7/noisy/development/dev_*.json`. Они не относятся к независимой проверке на новых письмах.

Исходники внешнего современного новостного корпуса не перераспространяются. В пакет включены параметры прежней модели и короткие использованные отрывки писем из общественного достояния. Новые тексты не являются гарантированно отсутствующими в книгах-источниках стороннего частотного словаря.
