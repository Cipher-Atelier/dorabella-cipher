# Статическое исправление распознавания — не запущено

Дефект доказан сохранённым STOP: run_staged.py:135–138 применяет поиск подстроки ко всем аргументам cmdline. Два совпадения имеют argv0 codex-linux-sandbox, а путь run_staged.py содержится внутри единого shell-command argument текущего вызова. У них нет отдельного script argv. Оболочки существуют вне исключённой цепочки видимых предков; недоступный pid_namespace отражён как null. Это не обнаружение старого Perl/runner. Нельзя исправлять это blanket-исключением всех внешних namespaces или удалением проверки процессов.

В отдельном prospective файле изменён только выбор совпадений: полные известные script paths сравниваются с отдельными argv-элементами на точное равенство; shell command carriers сохраняются отдельно в evidence. Точные пути относятся к новому каталогу BASE, завершённому fixture и прежнему original entrypoint. Неясный namespace у точного script match не освобождает gate. Это консервативный критерий: forwarding wrapper с отдельным script argv тоже остановит запуск. Он не обещает обнаружить переименованный или полностью скрытый код и не заменяет immutable attempt-directory gate.

Все дальнейшие hash/resource/namespace/group/signal/timeout/AS/CPU gates неизменны. Источник v1 не изменён, повтор не выполнялся. Этот prospective файл ещё не является новой разрешённой попыткой или готовым новым freeze: перед будущим использованием нужны новая версия, явный diff/hash и нижеследующая конечная проверка селектора внутри её исходного общего бюджета, без исполнения Perl.
