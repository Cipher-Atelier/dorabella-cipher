# Recheck of archived Dorabella round11 — 2026-10-02

This package contains NEW integrity checks, numerical verification, logs, and 18 fresh full-prefix reruns of the existing round11. It is NOT a new hypothesis search, and is NOT self-contained without the original laboratory.

Required: unpack `dorabella_lab_round10.zip` (SHA-256 in REPORT_RU.md) and `dorabella_round11_update.zip` into a separate working directory. Keep an immutable copy of both inputs. The archive_manifest.json in this package hashes every original file and both archives.

reproduce.py always uses a fresh directory; ordinary run.py on completed inputs is only a cache read. All18 new repeat outputs and their 720 checkpoint pairs are included under fresh_repetitions. The fourth old fresh-* directory from the original archive is deliberately NOT counted or included as a new computation.

`verified_results/summary.json` is an unchanged inherited summary, not a newly executed search. Current recomputed aggregate numbers are in audit_summary.json; the other 94 result files were regenerated by verify.py in the separate work copy.

`unchanged_source/` preserves the exact round11 source files used; import dependencies and scoring arrays are provided by the required original laboratory. New wrapper scripts capture this session's absolute paths and recorded fresh directory names; use the standard commands above for a new independent reproduction. Commands, UTC timestamps and limitations are recorded in the logs and REPORT_RU.md.

No new external historical sources were used. No background computation is claimed.
