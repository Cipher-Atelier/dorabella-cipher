## Что находится в компактном архиве

code и data содержат исполняемый код, замороженный scorer, все входы и исходные ответы контролей. Численная функция поиска получает только glyph, kind и id, без ответов/ключей.

frozen_protocol.json содержит протокол и хеши численных зависимостей. Его SHA256:
43de9f2fc5dec87c13e9ec9a68d58295aed951a4d865f32c9648a0ff86f2a4a3

Оригинальные завершённые результаты лежат в evidence/reference_results; полные метаданные 3760 блоков и хеши численных массивов в evidence/main_checkpoints; отдельный аудит без отсечений в evidence/unpruned_audit; логи в evidence/logs.

Для компактности архив НЕ содержит 3760 численных NPZ-массивов checkpoints, установленных пакетов/JIT-кеша и исходных больших ZIP предыдущих раундов. Основные NPZ сохранены в рабочей папке расчёта; их SHA256 включены. Самостоятельный запуск ниже вычисляет их заново. Полные матрицы шестикратного неотсечённого аудита вычислялись, но не сохранялись; сохранены их хеши и все максимумы/ничьи.

FULL_RUN_MANIFEST.sha256 фиксирует файлы исходного завершённого расчёта, включая NPZ, отсутствующие в компактном архиве. BUNDLE_MANIFEST.sha256 проверяет только действительно включённые файлы архива. Это разные манифесты.

checks/independent_review содержит код и отчёт дополнительной проверки. Три минимальных исходных файла, нужные для этой проверки, включены в соседнюю папку dorabella_audit. Большие исходные ZIP не включены. Проверку можно повторить командой python checks/independent_review/independent_review.py из папки dorabella_round13.

## Гарантированно новый полный запуск

Распакуйте архив в НОВУЮ папку. Python 3.12; проверенные версии указаны в requirements.txt. В этой папке:

    python3.12 -m venv .venv
    . .venv/bin/activate
    python -m pip install -r requirements.txt
    export OPENBLAS_NUM_THREADS=1 NUMBA_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1
    python code/reproduce_bundle.py

Это заново выполняет 94 полных поиска, независимую проверку, 14 полных блоков, 6 неотсечённых полных аудитов и сравнение score/key/ties/decoded с сохранёнными результатами. В конце reproduction_verified.json должен содержать status=passed. При прерывании повтор той же команды возобновляет верифицированные checkpoints; для полностью нового пересчёта снова используйте новую распаковку.

Для одной быстрой независимой воспроизводимой положительной проверки:

    python code/run.py --case bailey_01 --workers 1
    python code/verify.py --case bailey_01

Ожидается key_id=28848947, S87=-3.044027022020651, 87/87, одна точная ничья. Строгие сохранённые float64-результаты получены на указанном в environment.json окружении. Другой компилятор или архитектура могут потребовать расследования округления; не меняйте правило выбора ключа молча.

code/freeze.py и code/prepare_engine.py сохраняются как происхождение протокола. Не запускайте их поверх полученного архива; уже замороженный протокол нельзя перезаписывать. code/summarize.py использовался в исходной рабочей папке и проверяет её исходные архивные файлы; для автономного пакета используйте reproduce_bundle.py.

## Ограничения интерпретации

Семейство: 8! × 3 × 2^8 ключей, фиксированные тройки ABC DEF GHI KLM NOP QRS TUW XYZ, общая средняя позиция, независимо обращаемые направления каждой ориентации. Нет перестановки позиций, исправлений глифов, команд или произвольных подстановок.

Целевая функция S87=C87+0.5W87. Глобальная оптимизация точна в этом семействе и при этой float64 функции. local Smax в stats относится лишь к неотсечённым оценённым ключам группы и не является точным локальным максимумом группы.

Контроли сохраняют частоты глифов, направленные биграммы и концы. Каждая транскрипция анализируется отдельно; одинаковые начальные seeds не делают две перестановки одинаковыми и не дают совместного теста лучшей транскрипции. Хвосты не корректированы на многолетний адаптивный выбор гипотез.
