# Воспроизведение раунда 9

Распакуйте полный `dorabella_lab_round9.zip`. Все команды ниже выполняются из папки `dorabella_lab`. Сохранённые результаты позволяют проверить выводы без нового внешнего скачивания.

## Среда

Проверено на Python 3.13.5 и g++ 14.2.0. Для нового раунда достаточно NumPy, Numba, SciPy и SymPy:

```bash
python -m venv .venv
# Активируйте окружение способом своей ОС.
pip install -r round9/requirements_round9.txt
```

Понадобится C++17-компилятор `g++` в PATH для повторного перечисления. Код использует Python-модули прошлых раундов, уже входящие в полный архив. Их языковые модели и словари в новых расчётах не запускаются.

## Прочитать результаты

Основной журнал: `round9/dorabella_round9_research_log.md`.

JSON-сводки:

```text
round9/results/geometry/summary.json
round9/results/change_point/summary.json
round9/results/literal_walk.json
round9/results/final_audit.json
```

Чтение массивов без стороннего формата:

```python
import numpy as np
z = np.load('round9/results/geometry/hauer_real_bigram_mc.npz')
sequences = z['sequences']       # 99999 x 87
energy_pairs = z['energy_pairs'] # 99999 x 3 x 2; 2E = A + B*sqrt(2)
```

В change_point NPZ: `sequences` и `statistics`; 64 столбца соответствуют разрезам 12..75. В геометрических `*_rowN.npz` находятся полные допустимые строковые множества, не случайные подвыборки.

## Полный повтор нового раунда

Сначала сохраните резервную копию `round9/results`. Не изменяйте код/параметры/старые входы под прежними именами: два `freeze`-протокола обнаруживают несовпадение хешей.

```bash
python round9/geometry_order.py
python round9/change_point.py
python round9/literal_walk.py
python round9/audit_round9.py --old-archive /полный/путь/dorabella_lab_round8.zip
```

Геометрическая программа заново перечисляет строковые множества и перезаписывает только свои новые результаты. Программа разрезов заново создаёт все свои случайные последовательности и оценивает их; полные триграммные множества использует из неизменённого `round8/results`. Частичного возобновления у новых программ нет. Начатый, но прерванный запуск не считайте полным результатом.

Аудит сверяет все 7336 прежних файлов с исходным ZIP, полностью воспроизводит 399996 геометрических случайных путей, пересчитывает все сохранённые G² и повторяет префиксы случайных генераций проверки разрезов. Для подтверждения побайтовой сохранности старого архива нужен сам ZIP раунда 8; он не вложен вторым ZIP в ZIP раунда 9. Вместо этого все его распакованные файлы уже сохранены, а их хеши включены в `round9/results/old_archive_file_hashes.json`.

Ожидаемые сводные результаты перечислены в журнале. На другой платформе возможны небольшие различия последних знаков float64 в G²; геометрические сравнения используют целые коэффициенты. Неполное совпадение нельзя скрывать заменой сохранённых результатов.

## Объём и границы

Готовые `.npz` сохранены целиком, в том числе случайные последовательности и невыгодные результаты. Числа перебранных записей не равны числу независимых исторических документов. Протоколы фиксируют текущие процедуры, а не устраняют поисковый характер всей серии.

Новые raw-изображения не включены: попытки скачивания не удались. Нет нового установленного plaintext/ключа и новой слепой разметки.
