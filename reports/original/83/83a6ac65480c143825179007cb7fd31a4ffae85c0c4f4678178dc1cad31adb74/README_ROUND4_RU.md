# Dorabella: раунд 4 — поиск ключа с непосредственной словарной оценкой

Это продолжение предыдущих трёх раундов. Архив содержит их исходные файлы и новые файлы раунда 4. Он не заменяет проверку транскрипции или независимую криптоаналитическую экспертизу.

Главный файл нового журнала: `dorabella_round4_research_log.md`.

## Воспроизведение

```bash
python -m venv .venv
# Активируйте окружение способом, принятым в вашей ОС.
pip install -r requirements_round4.txt
python checks_v4.py
python run_v4.py --group all --workers 4
python summarize_v4.py
python check_cached_dorabella_v4.py
python final_checks_v4.py
```

`run_v4.py` использует фиксированные настройки и данные из `results/v4/frozen_protocol.json` и `results/v4/inputs.json`, проверяет хеши программы/модели и пропускает уже завершённые расчёты. Для выполнения порциями: `--max-new 4`. Для отдельной группы: `--group regression`, `heldout`, `real` или `null`.

Для нового полного пересчёта **сначала сохраните копию архива**, затем удалите `results/v4/cases` и `results/v4/banks`. Исходные результаты раунда 3 для знакомых примеров и Dorabella используются как неизменённые промежуточные банки; для новых писем и новых перестановок заново выполняются и отбор v2, и v3, и v4. Чтобы повторить также старый этап Dorabella, используйте исходный `scan_v2.scan_one` и `scan_v3.Pipeline` с той же транскрипцией и сравните с сохранёнными банками. `final_checks_v4.py` полностью повторяет сам новый v4-поиск Dorabella, не старые этапы.

Файл `cases_v4.py` сохраняет 12 новых отрывков и все входы; он не нужен для стандартного пересчёта, так как `inputs.json` уже включён. Полный Gutenberg-том не требуется и в архив не включён. Частотный словарь читается из закреплённого TextBlob; его хеш проверяется. Символьная языковая модель включена.

## Границы новой процедуры

* 672 определения автоматов остаются прежними. Новая оценка применяется внутри **финального поиска ключей**, но не заменяет ранний отбор автоматов.
* Финалисты: прежние восемь лучших схем плюс исходная последовательность, если её нет среди восьми.
* На финалиста: 64 перезапуска по 16 000 предложений. На каждом предложении оценивается сочетание символьного балла и словарной сегментации.
* 25% предложений пробуют целое словарное слово на участке с точно таким же рисунком повторов; остальные меняют местами два значения ключа. Все изменения сохраняют взаимно однозначную подстановку.
* Это эвристическая оптимизация, не выборка из вероятностного распределения расшифровок.
* `ablate_v4.py` — только диагностическое сравнение на трёх старых трудных примерах. Оно отключает групповые предложения, но сохраняет словарную оценку и число шагов. Оно не меняет зафиксированный основной протокол.

Папка `results/v4/cases` содержит все результаты, `banks` — новые промежуточные результаты, `summary.json` — численную сводку, `implementation_checks.json` и `final_integrity.json` — технические проверки.

Ни связность текста, ни правильность механизма не следуют автоматически из высокого балла или обратного шифрования. Фрагменты известных тестов служат проверкой метода, а не расшифровкой Dorabella.
