# Dorabella cipher research archive

**Assembly in progress. No accepted decipherment is claimed.**

This repository will preserve screened research reports, code, saved results and their limitations, with original byte hashes and English navigation. Original archives remain outside Git during rights and privacy review.

No research script, scorer, key search or experiment is executed for this archival work. Paid books, restricted scans, personal correspondence, raw private chats, credentials and reference-only British Library images and derivatives are excluded. No blanket license is granted over third-party materials.

The repository was created private, then made public with separate user authorization after its empty remote history was checked. Further deposits are subject to file and history screening.
